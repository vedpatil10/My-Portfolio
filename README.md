# Vedant Patil — Modern Dark Portfolio

A stunning dark-themed portfolio with advanced animations, particle effects, and modern UI. Built with vanilla HTML, CSS, and JavaScript for maximum performance.

## ✨ Features

- **Dark Theme**: Modern dark UI with glassmorphism effects
- **Advanced Animations**: Particle system, custom cursor, floating elements
- **Responsive Design**: Perfect on all devices
- **Real Projects**: Showcase actual work with hover effects
- **Skills Visualization**: Animated progress bars
- **Resume Downloads**: Multiple tailored resume versions
- **Contact Form**: Netlify-ready contact form
- **Theme Toggle**: Switch between dark and light themes

## 🚀 Quick Start

### Local Development
```bash
# Navigate to project folder
cd "C:\Users\HP\OneDrive\Desktop\portfolio"

# Serve locally (choose one)
python -m http.server 8080
# OR
npx serve -l 8080 .

# Open http://localhost:8080
```

### Customize Your Details

**Update these in `index.html`:**
- Replace `vedant.patil@email.com` with your real email
- Update LinkedIn URL: `https://linkedin.com/in/vedant-patil`
- Update GitHub URL: `https://github.com/vedpatil10`
- Add your real project links in the Projects section
- Update project descriptions with your actual work

**Add your images to `assets/` folder:**
- `me.jpg` - Your profile photo (hero section)
- `about.jpg` - About section image
- `project1.jpg`, `project2.jpg`, `project3.jpg` - Project images

## 🌐 Deploy to Production

### Option 1: Vercel (Recommended)
```bash
# Push to GitHub
git init
git add .
git commit -m "feat: modern dark portfolio"
git branch -M main
git remote add origin https://github.com/vedpatil10/Portfolio.git
git push -u origin main

# Deploy on Vercel
# 1. Go to vercel.com
# 2. Import your GitHub repo
# 3. Framework: "Other"
# 4. Deploy
```

### Option 2: GitHub Pages
```bash
# After pushing to GitHub
# 1. Go to repo Settings → Pages
# 2. Source: Deploy from a branch
# 3. Branch: main, folder: /
# 4. Save
```

### Option 3: Netlify
- Drag and drop the folder to Netlify dashboard
- Or connect your GitHub repo
- Contact form works automatically with Netlify
